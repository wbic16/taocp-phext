# The Art of Computer Programming with Phext

This repository tracks my reading/study of TAOCP, with the benefit of hindsight (2025, SSDs, and Phext).

I've organized my notes into a phext document, which you can interact with in a fine-grained manner. The libphext-rs and libphext-node implementations, along with phext-shell and SQ, existed at the start of my journey through TAOCP.
